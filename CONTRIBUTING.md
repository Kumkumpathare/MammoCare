# Contributing to MammoCare

Contributions that improve code quality, reproducibility, documentation, testing, and research methodology are welcome.

## Getting Started

1. Review the project documentation in `README.md`.
2. Fork or clone the repository, depending on your access.
3. Set up the development environment and install the required dependencies.
4. Review existing issues and pull requests before starting substantial changes.

## Development Workflow

1. Create a feature branch from the latest `main` branch.
2. Keep changes focused and commits descriptive.
3. Run relevant tests and quality checks.
4. Update documentation when necessary.
5. Open a pull request against `main`.

Contributors with write access may create feature branches directly in the repository. Others should submit changes from their forks.

## Contribution Guidelines

- Follow the existing project structure and coding conventions.
- Write clear, maintainable, and appropriately documented code.
- Add or update tests for relevant changes.
- Avoid unrelated modifications in a single pull request.
- Document significant implementation and methodological decisions.

## Research and Data Integrity

- Respect dataset licences, privacy requirements, and usage restrictions.
- Document relevant data sources, preprocessing steps, and experimental assumptions.
- Never commit private patient information, credentials, or sensitive data.
- Ensure research claims and reported results are supported by evidence.
- Preserve reproducibility when modifying experiments or evaluation procedures.

## Pull Requests

Each pull request should clearly explain its purpose, summarize the changes, and describe the relevant tests performed. Include related issues and known limitations where applicable.

## Communication

Use the repository's available GitHub Issues or Discussions for questions, bug reports, and proposed improvements.

Thank you for contributing to MammoCare.
