# Security Policy

## Reporting a Vulnerability

If you discover a potential security vulnerability in MammoCare, please report it privately through [GitHub Private Vulnerability Reporting](../../security/advisories/new), if enabled.

Please do not disclose vulnerabilities publicly until they have been reviewed and addressed.

## Scope

Security reports may include:

- Exposed credentials, API keys, or sensitive information.
- Vulnerable dependencies or insecure configurations.
- Security weaknesses in data handling or application code.

## Response

Reports will be reviewed by the project maintainers. Any remediation and disclosure timeline will depend on the severity, impact, and complexity of the issue.

## Responsible Disclosure

Please provide sufficient information to help reproduce and assess the issue. Avoid accessing, modifying, or disclosing data that does not belong to you.

Thank you for helping keep MammoCare secure.
