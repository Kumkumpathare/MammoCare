# Security Policy

MammoCare is an academic research repository. Security reports are welcome for issues affecting its code, dependencies, repository configuration, or handling of research artefacts and data.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately through [GitHub Private Vulnerability Reporting](https://github.com/aryanap07/MammoCare/security/advisories/new), if the feature is enabled for this repository.

If private vulnerability reporting is unavailable, contact a repository maintainer privately through an established GitHub contact route. **Do not** publish exploit details, credentials, private data, or a vulnerability report in a public issue or discussion before maintainers have had a chance to review it.

When reporting an issue, include:

- A concise description of the suspected vulnerability and its possible impact.
- The affected file, dependency, workflow, commit, or configuration, if known.
- Minimal steps or a small example that allows maintainers to reproduce the issue safely.
- Any relevant version or environment details.

Do not include live credentials, patient information, or other sensitive material in the report.

## Scope

Examples of in-scope reports include:

- Accidentally exposed credentials, access tokens, or private configuration.
- Vulnerable or unexpectedly installed dependencies.
- Unsafe handling of downloaded data or generated artefacts.
- Repository or workflow configuration that creates an unintended security exposure.
- Code paths that could disclose data not intended for publication.

Research limitations, model performance disagreements, data-quality problems, or incorrect scientific conclusions are not automatically security vulnerabilities. Report those through the repository's public issue or discussion process unless they also involve a security concern.

## Response and Disclosure

Maintainers will review reports and may request additional information. Any remediation and disclosure timeline will depend on severity, impact, and complexity. A report does not guarantee a particular response time or that a proposed fix will be accepted.

Please allow maintainers a reasonable opportunity to assess and address a verified issue before disclosing it publicly.

## Responsible Use

Do not access, modify, or disclose data that does not belong to you. Do not upload private patient data, credentials, or sensitive information to the repository, issues, pull requests, or discussions.

Thank you for helping keep MammoCare and its research workflow secure.
